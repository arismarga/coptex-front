# Coptex Frontend

Next.js frontend for the Coptex headless WordPress/WooCommerce catalog.

## Local Development

1. C:\Users\Aris\Desktop\Coptex
2. git clone https://github.com/arismarga/coptex-frontend.git frontend
3. cd frontend
4. npm install
5. npm run dev

## Environment

Create a `.env.local` file:
NEXT_PUBLIC_WP_BASE_URL=http://coptex.local
NEXT_PUBLIC_SITE_URL=http://localhost:3000
